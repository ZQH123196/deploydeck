# 05 克隆实例

## 目标

源实例无法开机时，按部署配置的规格优先级克隆到新主机，并等到克隆完成。

## 背景

克隆是控制台功能，无 API。源实例必须已关机。系统盘固定克隆，数据盘可选。今日剩余克隆次数界面显示为 10。

## 范围

1. 前置校验：源实例已关机；当日剩余克隆次数大于 0。任一不满足即失败，不尝试。
2. 打开「更多」→「克隆实例」。
3. 按部署配置的 `cloneDataDisk` 勾选数据盘。稀疏文件优化默认开启。
4. 点「继续」，进入选主机页面。
5. 按部署配置的 `gpuPreference` 顺序选择目标主机。不跳档，不先选低配再升降。
6. 确认创建。
7. 轮询新实例：状态从 `克隆锁定中` 变为其它即视为完成；超时转 ESCALATED。
8. 记录新实例 ID 与源实例 ID 的对应关系。

## 不做

不做跨地区迁移。不做批量克隆。

## 验收

1. 对一台已关机实例执行克隆，能得到一台新实例，状态最终为 `已关机` 或 `运行中`。
2. 配额为 0 时失败，错误信息包含「今日克隆次数已用尽，可改用开机复用路径」。
3. 选主机页面的规格顺序与 `gpuPreference` 一致。
4. 克隆全流程留截图与步骤日志。
