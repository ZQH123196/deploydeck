# 04 开机与状态轮询

## 目标

让一台已关机实例开机，并判定开机成功或失败。

## 背景

行内「开机」按钮。开机失败最常见的原因是目标主机没有可用 GPU。

## 范围

1. 定位实例行，点「开机」。
2. 轮询状态直到 `运行中`，或超时。
3. 判定开机失败：出现无可用 GPU 提示，或超时未到 `运行中`。
4. 失败时返回明确原因，供 05 号 ticket 决定是否走克隆。
5. 不使用「无卡模式开机」。该路径只允许人工触发。

## 不做

不做「升降配置」。不做多实例批量开机。

## 验收

1. 对一台已关机实例执行开机，能到达 `运行中`。
2. 人为制造失败场景（例如选一台 GPU 被占满的主机），能区分「无可用 GPU」与「超时」两种原因。
3. 开机动作前后各留一张截图。
