# 08 关机、释放与终态验证

## 目标

销毁实例，并证明该实例已从控制台消失。

## 背景

关机请求返回成功不等于实例已停。释放请求成功不等于实例消失。计费按实例存在判定。因此终态必须验证。

## 范围

1. 关机：点行内「关机」，轮询直到状态为 `已关机`。
2. 释放：「更多」→「释放实例」→ 确认。
3. 终态验证：轮询实例列表，直到该实例 ID 不再出现。
4. 超时未消失：状态置 `ESCALATED`，退出码 2，不自动重试。
5. 释放需要二次确认弹窗，按确认。
6. 全流程留截图与步骤日志。

## 不做

不做强制删除。不做跨账号。

## 验收

1. 对一台测试实例执行销毁，最终列表查不到该 ID。
2. 人为中断验证（例如超时设成 1 秒），能得到 `ESCALATED` 而非成功。
3. 销毁后账本写入停机时刻与金额。

## 备注

释放不可恢复。本 ticket 的实机验证由人发起，用一台专门为此建的实例。
