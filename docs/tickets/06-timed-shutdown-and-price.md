# 06 定时关机与单价读取

## 目标

部署成功后自动设置平台定时关机，并从控制台取得单价。

## 背景

每行有「设置定时关机」入口。对话框显示服务器时间、关机时间输入、预计消费、账户余额。官方 API 的单价字段单位未标注，标准实例没有 API，故单价只能从控制台读。

## 范围

1. 点击「设置定时关机」。
2. 读取对话框里的服务器时间。后续计算一律以它为准，不用本机时钟。
3. 填入关机时刻：计划过期时刻减 5 分钟安全余量。
4. 读取「预计消费」，用「预计消费 ÷ 时长」反推单价，落盘。
5. 点「确定」，再读列表确认该行出现定时关机标记。
6. 读取账户余额，用于余额熔断。

## 不做

不做定时关机的时间精度优化。分钟级即可。

## 验收

1. 设置后列表该行能读回定时关机状态。
2. 反推单价与部署配置里缓存的历史单价偏差超过 20% 时报错，并提示更新缓存。
3. 服务器时间与本机时间偏差超过 5 分钟时告警，但仍以服务器时间为准。

## 备注
