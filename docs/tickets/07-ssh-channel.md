# 07 SSH 数据面

## 目标

deploydeck 能通过 SSH 在实例内执行命令，并把完整输出落盘。

## 背景

AutoDL 只提供 root 加密码登录。密码在控制台 SSH 登录列。Windows 与 Linux 要同一条代码路径，故用 Node `ssh2`。已有脚本 `start_trans_app.sh` 等需要被远程调度。

## 范围

1. 从控制台 SSH 登录列取登录指令与密码。
2. 建立 SSH 会话，校验主机密钥。首次连接记录指纹，指纹变化即失败。
3. 执行单条命令：独立超时、流式收集输出、返回退出码。
4. 输出落盘：完整写入 run 日志目录，摘要保留尾部 200 行。
5. 日志里禁止出现密码。只记「已取得密码」。
6. 断线重连一次。重连后不重放已确认失败的命令。

## 不做

不做 SFTP 批量传文件。代码走 git clone。

## 验收

1. 对一台运行中实例执行 `echo ok`，退出码 0，输出落盘。
2. 密码错误时失败，错误信息不含密码本身。
3. 命令超时被杀，返回明确超时错误，退出码 1。
4. 主机密钥指纹变化时拒绝连接，退出码 2。
