# 真机端到端测试（耗费测试）

本目录的用例会**动真实的 AutoDL 实例**：开关机、设平台定时关机、克隆、释放。
它们产生真实费用，消耗每日克隆配额，所以与常规单测完全分开。

## 与常规测试的分工

| 套件 | 入口 | 跑什么 | 花钱 |
|---|---|---|---|
| 常规单测 | `pnpm test` | `src/**/*.spec.ts`，全部走假通道 | 否 |
| 真机测试 | `pnpm test:e2e` | `e2e/**/*.e2e.test.ts`，连真实控制台与 SSH | **是** |

`pnpm test` 的 `include` 由 `vitest.config.ts` 钉死在 `src/`，本目录不会被误跑。

## 授权

三个环境变量必须同时给，缺一个就拒绝运行，且不会做任何控制台动作。

| 变量 | 含义 |
|---|---|
| `DEPLOYDECK_E2E=1` | 开关。没它一律不跑 |
| `DEPLOYDECK_E2E_SOURCE_INSTANCE=<实例 ID>` | 用作开关机对象与克隆源的实例。必须是**已关机**实例，测试会先校验 |
| `DEPLOYDECK_E2E_APPROVE_COST_YUAN=<元>` | 本次批准的最大花费。低于预计花费直接拒绝 |

第三个变量是审核动作本身：人必须先把钱数写下来。预计花费见
`src/../e2e/support/gate.ts` 的 `COST_ESTIMATES`，当前合计约 0.43 元
（开关机 0.05 + 定时关机 0.08 + 克隆 0.30，按 vGPU-32GB 1.58 元/时估算）。

可选变量：

| 变量 | 默认 | 含义 |
|---|---|---|
| `DEPLOYDECK_E2E_CDP_PORT` | `9222` | 已登录的专用 Chrome 的 CDP 端口。测试不做登录自动化 |
| `DEPLOYDECK_E2E_INSTANCE_NAME` | `deploydeck-e2e` | 克隆产物名。用例会断言改名后等于它 |
| `DEPLOYDECK_E2E_GPU_PREFERENCE` | `v-32g-p` | 克隆的算力规格优先级，逗号分隔 |
| `DEPLOYDECK_E2E_CLONE_TIMEOUT_MINUTES` | `45` | 克隆等待上限，分钟。实测约 7 分钟 |

跑法：

```bash
DEPLOYDECK_E2E=1 \
DEPLOYDECK_E2E_SOURCE_INSTANCE=<已关机实例 ID> \
DEPLOYDECK_E2E_APPROVE_COST_YUAN=1 \
pnpm test:e2e
```

前置条件：专用 Chrome 已登录 AutoDL 控制台，且 CDP 端口可连。

## 用例清单

| 用例 | 真实动作 | 预计花费 |
|---|---|---|
| 【耗费·只读】实例列表可解析 | 读列表，校验源实例已关机 | 0 |
| 【耗费·只读】余额与克隆配额可读 | 开定时关机对话框读余额、开克隆对话框读配额 | 0 |
| 【耗费·UI·慢】开关机 | 开机 → 运行中 → 关机 → 已关机 | 约 0.05 元 |
| 【耗费·UI·慢】平台定时关机 | 开机 → 设 2 分钟后关 → 等平台自动关 | 约 0.08 元 |
| 【耗费·UI·慢】克隆 → 改名 → 释放 | 克隆（双盘）→ 改名 → 释放 → 确认消失 | 约 0.30 元 |

标签沿用 `AGENTS.md` 测试规范：`耗费`（花钱）、`UI`（要起界面）、`慢`（非快速测试）。

## 清理保证

- 用例只碰两个对象：`DEPLOYDECK_E2E_SOURCE_INSTANCE` 那一台，以及它自己克隆出来的实例。
- `afterAll` 负责释放克隆产物、关掉源实例，失败也继续清下一个。
- 清理失败会在输出里点名实例 ID，交人工处理，不静默吞掉。
- 工作目录、配置目录、状态目录全落 `.tmp/e2e/<时间戳>/`，与人工使用的
  `~/.config/deploydeck`、`~/.local/state/deploydeck` 隔离。

## 产出

每次运行在工作目录下写 `report.json`，并打印人读表格：

- 每个用例的起止余额、余额差额、耗时、说明。
- 批准额度与预计花费，便于事后对账。

注意：按量计费不是逐秒结算，余额差额可能小于真实花费。报告同时给耗时与单价，
不要只看差额下结论。

## 跑完之后的现场

- 克隆产物与源实例都会被关机/释放，不留运行中的实例。
- 源实例上已触发的定时关机记录会由 `afterAll` 自动清掉（走 `clearTimedShutdown`）。
  定时关机用例本身也会在到点关机后立即清除并断言清空，所以这条路径每次跑都被覆盖。
  如果清理失败，输出会点名实例 ID，人工点列表里的「关闭」即可。
- 每次运行的截图、动作日志与 `report.json` 留在 `.tmp/e2e/<时间戳>/`。

## 已知平台问题

有的实例会长时间停在「克隆锁定中」（服务端状态 `shutdown_cloning`），此时释放与重置都不可用。
这类实例不要选作 `DEPLOYDECK_E2E_SOURCE_INSTANCE`，测试会在列表校验阶段失败并停下。
